Add Auth Token

Steps:

  1. Open a browser incognito/private window
  2. Visit chat.deepseek.com and log in
  3. Extract the token — pick one method for your device (both are kept, either works):

Method A · Desktop / Android (with developer tools)

Open developer tools (F12) → Console → paste:

JSON.parse(localStorage.getItem("userToken")).value

Method B · iPhone / iPad (Shortcuts) — recommended, verified to work

Use the Shortcuts action "Run JavaScript on Web Page" to extract it. It has full page access and, unlike bookmarks, won't be blocked by iOS with "The operation is insecure":

  1. Shortcuts app → tap + in the top-right to create a new one → add the action "Run JavaScript on Web Page" → paste this into the script box:
var out = '';
try {
  var r = localStorage.getItem('userToken');
  if (r) { try { out = JSON.parse(r).value || r; } catch(e) { out = r; } }
} catch(e) { out = ''; }
if (out) { completion(out); } else { completion('Nothing retrieved: make sure Safari is logged in to chat.deepseek.com'); }
  1. Add another action "Copy to Clipboard"
  2. Crucial step (missing it causes "no result after running"): at the bottom of the shortcut editor, set "Receives" → type to "Safari Web Page", and make sure the JS action's "Web Page" input is connected to the previous step
  3. Usage: in Safari, open chat.deepseek.com while logged in (after the page fully loads) → tap Share → Run Shortcut → the token goes to your clipboard and a popup shows it
