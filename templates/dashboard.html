When do tokens expire? Unpredictably — DeepSeek's server decides, and there is no way to know in advance. Expired tokens surface as 401 or 503 No tokens available on the client.
Can't tell expired from muted? Log into chat.deepseek.com with that account: a re-login prompt = expired; a mute notice when sending = muted; normal chatting = false positive, just press "Restore".
Safe to try: the "Restore" button is always safe — a truly dead token simply re-quarantines automatically, no harm done.

Add an auth token

A token is equivalent to your DeepSeek account: paste it only into your own dashboard, never share it. Logging out of DeepSeek in the browser invalidates it.
Token lifetime is unpredictable — it can expire at any time. When the status column shows "Likely expired", extract a fresh token using the methods below and add it; then delete the old one.
How do I get a token? Pick any one of the three methods

Method A · Desktop / Android (easiest)

  1. Open an incognito window and sign in at chat.deepseek.com
  2. Press F12 to open DevTools → switch to the Console tab → paste this line and hit Enter:
JSON.parse(localStorage.getItem("userToken")).value

The long string it prints is the token — copy it.

Method B · iPhone / iPad (Shortcuts — verified working)

  1. Open the Shortcuts app → tap + to create a new one → add the action "Run JavaScript on Web Page" and paste this into the script box:
var out = '';
try {
  var r = localStorage.getItem('userToken');
  if (r) { try { out = JSON.parse(r).value || r; } catch(e) { out = r; } }
} catch(e) { out = ''; }
if (out) { completion(out); } else { completion('Nothing found: make sure Safari is signed in to chat.deepseek.com'); }
  1. Add another action: "Copy to Clipboard"
  2. Crucial step (skip it and the shortcut silently returns nothing): at the bottom of the shortcut editor, tap the receiving-types row → pick "Safari Web Page", and make sure the JS action's "Web Page" input is wired to the previous step
  3. Usage: open the signed-in chat.deepseek.com in Safari (wait for full load) → Share → Run the shortcut → the token lands in your clipboard
Method C · Safari bookmarklet (fallback: some iOS builds report "The operation is insecure" — if so, use Method B)

iOS does not allow running javascript: from the address bar; a bookmark is the only entry point. Some iOS builds also block localStorage reads from bookmarklets — if you hit an error, switch to Method B.

  1. Open any normal page in Safari → Share → Add Bookmark → Save
  2. In the bookmarks list → Edit that bookmark → replace the entire URL with the code below → Save
  3. On the signed-in chat.deepseek.com page, tap the bookmark to run it → auto-copied
