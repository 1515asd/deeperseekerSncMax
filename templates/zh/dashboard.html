添加认证令牌

令牌等同于你的 DeepSeek 账号：只贴进自己的面板，别给任何人。浏览器里退出 DeepSeek 登录后，令牌随之失效。
令牌有效期不固定，随时可能过期——仪表盘状态列显示「疑似过期」时，重新按下面的方法提取令牌再添加一次即可，旧令牌删掉就行。
怎么拿到令牌？三种方法选一种就行

方法 A · 电脑 / 安卓（最简单）

  1. 开一个无痕窗口，登录 chat.deepseek.com
  2. 按 F12 打开开发者工具 → 切到「控制台 / Console」→ 粘贴下面这行回车：
JSON.parse(localStorage.getItem("userToken")).value

输出的一长串就是令牌，复制它。

方法 B · iPhone / iPad（快捷指令，实测可用）

  1. 快捷指令 App → 右上角 + 新建 → 添加操作「在网页上运行 JavaScript」，脚本框粘贴：
var out = '';
try {
  var r = localStorage.getItem('userToken');
  if (r) { try { out = JSON.parse(r).value || r; } catch(e) { out = r; } }
} catch(e) { out = ''; }
if (out) { completion(out); } else { completion('未取到：请确认 Safari 已登录 chat.deepseek.com'); }
  1. 再添加操作「拷贝至剪贴板」
  2. 关键一步（漏了会"运行完没结果"）：编辑快捷指令底部「接收」→ 类型选「Safari 网页」，并确认 JS 操作的「网页」输入已连上上一步
  3. 使用：Safari 打开已登录的 chat.deepseek.com（页面加载完）→ 分享 → 运行快捷指令 → 令牌进剪贴板
方法 C · Safari 书签小工具（备选：部分 iOS 会报 The operation is insecure，报错就用方法 B）

iOS 不允许在地址栏直接执行 javascript:，书签是唯一入口。但部分 iOS 会禁掉书签脚本的 localStorage 读取——报错请改用方法 B。

  1. Safari 打开任意普通页面 → 分享 → 添加到书签 → 存储
  2. 书签列表 → 编辑该条 → 「地址」整段替换为下面的代码 → 存储
  3. 在已登录的 chat.deepseek.com 页面点书签运行 → 自动复制
javascript:(function(){var t='';try{var r=localStorage.getItem('userToken');if(r){try{t=JSON.parse(r).value||r;}catch(e){t=r;}}}catch(e){alert('读取失败: '+e.message+'（请改用方式 B 快捷指令）');return;}if(!t||t.length<20){alert('未找到 userToken。请确认已登录且页面加载完成');return;}var a=document.createElement('textarea');a.value=t;a.style.cssText='position:fixed;left:-9999px';document.body.appendChild(a);a.select();a.setSelectionRange(0,999999);var ok=document.execCommand('copy');a.remove();alert((ok?'已复制到剪贴板 ✓\n\n':'复制失败，请手动长按复制\n\n')+'长度 '+t.length+'\n'+t.substring(0,12)+'...');})();

安卓也可以用方法 C 的书签（新版 Chrome 同样禁止地址栏执行 javascript:），或继续用 F12 控制台。
