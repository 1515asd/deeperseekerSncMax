添加账号

⚠️ 使用模型说明（2026-11 起）：令牌出生在你自己的设备上，使用在服务器。
11 月起上游执行「跨环境会话吊销」：浏览器里提取的令牌拿到服务器使用，会被判定为会话盗用并整体吊销（频繁封号）。所以请不要再从浏览器提取令牌，改用下面的方式一：在自己设备上运行登录工具，让服务器把令牌直接发给你。
风险提示：新模型能否完全避免封号尚无定论，需要使用一段时间观察。请使用小号，账号被封无法承担责任。

方式一（推荐）· 在自己设备上登录：用登录工具向 DeepSeek 发送一次官方安卓 App 同款登录请求（走你自己的家庭网络），令牌随登录结果直接返回——出生即安卓，与桥的使用形态一致。

方法 A · 电脑（Windows / Mac / Linux，跑一次脚本）
  1. 装好 Python（没有的话去 python.org 装一个，勾选 Add to PATH）
  2. 下载登录脚本：tools/login_once.py（仓库里，右键另存为）
  3. 运行 python login_once.py，按提示输入账号、密码，可选设备指纹
  4. 输出的令牌复制，贴到下方「贴入令牌」表单

在公司/校园网或 VPN 下运行可能被 WAF 拦（脚本会自动检测并提示），换家庭宽带或手机热点即可。

方法 B · iPhone / iPad（快捷指令，不装任何 App）
  1. 快捷指令 App → 新建 → 添加两个「要求输入」（提示语：账号；密码）
  2. 添加「获取 URL 内容」：URL 栏填 https://chat.deepseek.com/api/v0/users/login，方式选 POST，展开「头部」，键和值是两个格子，分开填（冒号左边进键、右边进值，不要带冒号连粘）：
    键值
    content-typeapplication/json
    refererhttps://chat.deepseek.com/sign_in
    user-agentDalvik/2.1.0 (Linux; U; Android 14; Pixel 7)
  3. 展开「请求体」，类型选 JSON，同样一行一个键、键和值分开填：
    键值
    email（账号含 @ 用 email，手机号改用 mobile）选变量 → 你的「账号」输入
    password选变量 → 你的「密码」输入
    area_code+86（选「文本」类型）
    device_id（可选）设备指纹，见下方说明
    osandroid
  4. 添加「获取词典值」：键填 data.biz_data.user.token，词典来源选变量 →「URL 内容」的结果，再接「拷贝至剪贴板」（拷贝的对象是词典值的输出）。若返回为空，说明登录被拒，查看请求结果里的报错字段
  5. 运行 → 令牌进剪贴板 → 贴到下方表单

手机发请求不受浏览器 CORS 限制，且走的是你自己的移动网络，IP 天然干净。

方法 C · 安卓（Termux / HTTP Shortcuts）

命令行（推荐）：安装 Termux → pkg install curl -y → 下载仓库里的 tools/deepseek-login.sh → bash deepseek-login.sh，按提示输入账号密码，令牌随结果输出。

图形化（备选）：安装开源应用 HTTP Shortcuts → 导入 → 从 cURL 命令导入，粘贴 tools/deepseek-login.sh 里的 curl 段，再把账号密码改成自己的（建议用 App 变量）→ 桌面小组件一键登录。

设备指纹（可选 · 不知道有没有用）
真实安卓 App 登录时会携带数美 SDK 生成的设备指纹（89 字符 base64）。实测：伪造/随机的值会被上游直接拒绝（RISK_DEVICE_DETECTED），所以工具里留了这个可选项；但填了真实指纹能不能进一步降低风险，不知道有没有用——建议填，同一账号每次登录用同一个即可。获取方法：
  1. 电脑/安卓：Chrome 打开 chat.deepseek.com（不需要登录）→ F12 → 控制台执行 SMSdk.getDeviceId()（输出 undefined 就等几秒再执行一次）
  2. iPhone：用「在网页上运行 JavaScript」快捷指令在 chat.deepseek.com 页面（不登录）执行 completion(SMSdk.getDeviceId())，记得把「接收」类型设为 Safari 网页

贴入令牌：把登录工具输出的令牌粘贴到这里（不要带引号）。令牌等同于你的 DeepSeek 账号，只贴进自己的面板。

令牌有效期不固定，失效就再跑一次登录工具换新的，旧的删掉即可。面板「检测」按钮可查看每个令牌的真实状态（正常 / 禁言到几点 / 已作废）。
