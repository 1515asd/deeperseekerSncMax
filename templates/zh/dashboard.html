令牌什么时候会过期？不固定，由 DeepSeek 服务端决定，这边无法预知。过期后客户端会报 401 或 503 No tokens available。
分不清过期还是禁言？点「检测全部令牌」直接问 DeepSeek 每个令牌的真实状态。也可以登录 chat.deepseek.com 自查：网页提示重新登录 = 过期；发消息弹禁言提示 = 禁言；能正常聊 = 误判，点「恢复」即可。
放心试：「恢复」按钮是安全的——令牌真失效的话会自动再次隔离，不会造成损失。

添加账号

✨ 本版本起采用全新思路：发送这件事已经换了位置。
经过半天的研究，作者把此前的抽象问题彻底具象化——思路一转，困扰已久的登录、掉线、空回复等大量问题在方法层面就已消除，不再需要逐个打补丁。你只需要做一件事：在浏览器里正常登录 DeepSeek，把令牌取出来贴进面板。
风险提示照旧：请控制使用强度、只用小号，账号被封无法承担责任。
推荐 · 浏览器登录 + 书签取令牌（电脑、iPhone、安卓都适用，实测可行）
  1. 用 Safari / Chrome 打开 chat.deepseek.com，用账号密码正常登录。第一次可能要求邮箱验证：抄验证码填入，这是官方流程
  2. 登录成功后别关页面。
    • 电脑：F12 控制台执行 JSON.parse(localStorage.getItem("userToken")).value，复制输出
    • iPhone / iPad：点 Safari 底部「分享」→「添加书签」随便存一个 → 书签列表「编辑」→ 把该书签网址整段替换为：
      javascript:prompt('令牌如下',JSON.parse(localStorage.getItem('userToken')).value)
      然后回到 chat.deepseek.com 页面（必须停在该页面）点一下这个书签，弹框里就是令牌
  3. 把令牌贴到下方「贴入令牌」表单，完成

iPhone 书签点不出弹框 = 没登录成功（回第 1 步）或 Safari JavaScript 被关（设置 → Safari → 高级 → 打开）。令牌是你账号的钥匙，只贴进自己的面板。

贴入令牌：把取到的令牌粘贴到这里（不要带引号）。令牌等同于你的 DeepSeek 账号。

指纹一栏可不填：仅作备档展示，不加完全没有问题，官方目前也没有针对这个，可跳过。令牌有效期不固定，失效就重新取一个换上。

附录 · 电脑脚本登录（Windows / Mac / Linux，跑一次脚本）
  1. 装好 Python（python.org，勾选 Add to PATH）
  2. 下载登录脚本：tools/login_once.py（仓库里，右键另存为）
  3. 运行 python login_once.py，按提示输入账号、密码
  4. 输出的令牌复制，贴到上方「贴入令牌」表单

在公司/校园网或 VPN 下运行可能被 WAF 拦（脚本会自动检测并提示），换家庭宽带或手机热点即可。

附录 · 安卓（Termux / HTTP Shortcuts）

命令行：Termux → pkg install curl -y → 下载 tools/deepseek-login.sh → bash deepseek-login.sh。

图形化：HTTP Shortcuts → 从 cURL 命令导入粘贴 curl 段，账号密码改自己的（建议 App 变量）→ 桌面小组件一键登录。

附录 · 关于设备指纹（可不填，仅备档展示）
上游的登录接口对安卓协议登录有设备指纹校验（安卓真机 SDK 生成的格式才被接受，浏览器取到的短格式会被拒）——这只影响登录方式的选择，面板里的指纹一栏与此无关：它只是备档展示，面板不会用它发任何请求。不填完全没有问题，官方目前也没有针对这个，可跳过。
